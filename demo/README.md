# Chillax demo playlist

A playlist of open-licensed and public-domain films for trying Chillax and for app store review.

In Chillax, open Settings and set the M3U playlist URL to:

https://raw.githubusercontent.com/nkrvivek/chillax-releases/main/demo/demo.m3u

Films: Blender Studio open movies (Creative Commons Attribution) and films in the US public domain, streamed from Google's sample media bucket and the Internet Archive. Artwork and details from TMDB.
